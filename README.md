# Powersagitar Tap

## How do I install these formulae?

`brew install powersagitar/tap/<formula>`

Or `brew tap powersagitar/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "powersagitar/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
